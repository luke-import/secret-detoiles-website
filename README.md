# Secret d'étoiles — Site vitrine

Site vitrine de la marque de couches bébé Secret d'étoiles (Luke Import, La Réunion).

## Stack
- Astro 5 · Tailwind CSS v4 · TypeScript strict
- Fonts Fontsource : Sacramento, Fredoka Variable, Nunito Variable
- Hébergement : OVH mutualisé
- Déploiement : GitHub Actions → SFTP OVH

## Développement local
```bash
pnpm install
pnpm dev
```

Le site sera accessible sur http://localhost:4321
